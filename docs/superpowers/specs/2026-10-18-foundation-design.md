# 基础框架实施设计

依据：`docs/MASTER_SPEC.md` 和 `docs/reference/` 五张用户原型。用户已授权直接实施并在完成后提供验收文档。本轮交付基础框架，不宣称完成主规格全部 FR/AC。

## 本轮边界

实现快速监控看板、运行状态、视频源管理、系统设置四页及它们的真实持久化基础。固定七个一级导航；任务创建、智能体管理、模型管理保留禁用入口和说明，不创建这三个页面和可误入的空路由。后续 A/B 使用公共契约接入。

主规格给出的 Vue3、TypeScript、Vite、Naive UI、Pinia、Router、Axios、FastAPI、SQLAlchemy、Alembic、SQLite 和独立 Worker 保持不变。用 npm package-lock 和 Python requirements 锁定依赖。开发环境为当前 Windows x64，默认只监听回环地址；现场 OS/模型/性能尚未确定。

## 视觉

桌面展示四个页面原型中的层次；小屏折叠导航和明细栏。新安装正式页面显示真实空状态，不把原型里的 12/14、GPU 36%、事件列表或录像图伪装成真实数据。

## 真实功能

- 认证：首次初始化管理员，无默认密码；登录/注销、过期会话、密码安全哈希；写操作 CSRF，媒体和 WS 同会话鉴权。
- 视频源：文件分块上传、大小限制、真实 FFprobe 探测、必要时 FFmpeg 预览转码、来源元信息与 SHA-256；SQLite 持久化；摄像头添加、凭据加密保存/脱敏、测试和清晰的失败诊断；编辑/归档、筛选、详情和受保护文件预览。
- 看板：真实来源和最近事件查询、视频网格和详情；没有运行就显示空闲/未接入。由于创建及智能体模块未开发，不提供伪启动推理按钮。
- 状态：CPU/内存/磁盘实测，GPU 无采集器显示未知；API、Worker、FFmpeg、MediaMTX、本地模型的就绪分别显示。采样形成图表，刷新时不伪造历史数据。
- 设置：分类表单、校验、保存、刷新持久化、有效配置说明；服务地址局限于受控本地/局域网配置。未实现的许可证/授权信息显示未配置。
- 独立 Worker：持久作业队列领取、心跳、媒体探测与摄像头测试执行；租约过期可诊断。MediaMTX 缺失时如实标记不可用，不把 RTSP 字符串直接塞入浏览器播放。
- 公共边界：统一错误、request_id、UTC 时间、稳定 ID；OpenAPI 与生成 TS 类型；WS 状态通知及断线状态；事件、运行、模型和智能体只读契约/空查询供后续接入。

## 目录和模块

`frontend/src/app` 负责路由装配；`modules/{dashboard,runtime,sources,settings}` 负责页面；`shared/{api,realtime,media,ui,auth}` 提供公共设施。另外三模块仅在协作文档中定义接入方式。

`backend/app/main.py` 为组合入口，业务分 `modules/{auth,sources,runtime,settings}`，公共基础分 `shared/{db,errors,security,storage,jobs}`；契约不依赖 ORM。`worker/supervisor.py` 为独立进程。`contracts` 存 OpenAPI/示例和生成脚本；`deploy` 存配置及启动工具；`var` 运行目录不入 Git。
