# 开放场景视觉监测工作台（成员 A）

这是成员 A 负责的“任务创建 + 模型管理”模块原型。它使用浏览器本地存储保存演示数据，公共视频、需求解析、智能体和运行服务通过 `dist/mock-api.js` 模拟。

## 运行

```bash
python3 -m http.server 4173 -d dist
```

打开 `http://localhost:4173`。

## 已实现

- 固定模板与自然语言两种任务创建入口
- 视频源选择、录像区间和画面区域绘制
- 上传本地录像、读取分辨率与时长、选择分析片段
- 需求解析、模板优先匹配、多模态兜底评估
- 缺少区域/时长时阻止启动，修改后使旧校验失效
- Agent / Revision / Run 模拟创建与幂等启动
- 录像分析进度、事件命中、截图/片段证据和报警结果
- 报警证据弹窗、原录像交互播放、报警时间自动定位和证据引用展示
- 小模型与模板的一一绑定、搜索、筛选、新增、编辑和删除限制
- 本地大模型健康状态展示和用途切换
- 响应式页面、空状态、异常状态和操作提示

## 接入真实服务

页面只依赖 `mock-api.js` 导出的服务方法。录像目前通过浏览器本地对象 URL 预览，分析与报警使用 Mock 作业；接入真实环境时，应把录像文件提交给 SS-01 视频读取服务，并将分析作业与事件服务响应映射回页面。字段契约见 `openapi.yaml`。
